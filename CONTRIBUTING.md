# Contributing

Issues are welcome. Use the bug form for a defect.

Pull requests are not expected during the alpha. The harness changes through its own workflow, so
a pull request is likely to be closed.

`/lesson` is how you record a finding about how the harness behaves. The procedure is in
[.agents/skills/lesson/SKILL.md](.agents/skills/lesson/SKILL.md).

Report a vulnerability as described in [SECURITY.md](SECURITY.md), not as an issue.
