# Vault paths and writers

The CLI defines formats. MCP tool descriptions define the fields models use. Features and
ADRs carry type tags and `links:` metadata; use their tools to preserve identity and links.
Logs are typed callouts written by the log command.

| Path | Purpose and writer |
|---|---|
| `Dashboard.md`, `Index.md`, `bases/*.base` | Generated by `status render`. |
| `features/NNN-slug/plan.md` | CLI creates and manages status/tasks; manager edits narrative. See [[harness/document-editing]]. |
| `features/NNN-slug/log.md`, `features/NNN-slug/handoffs/` | Log and dispatch commands only. |
| `features/NNN-slug/retro.md` | Written by `/retro`. |
| `adrs/NNNN-slug.md`, `adrs/README.md` | Public harness decisions only; CLI creates ADRs and renders the index. |
| `decisions/NNNN-slug.md`, `decisions/README.md` | Private work decisions and generated index in the linked notes repo. |
| `journal/YYYY/MM-Month/DD-Weekday.md` | `/journal` writes generated block and properties; Notes belongs to the owner. |
| `usage/YYYY/MM-Month/DD-Weekday.<tag>.md`, `usage/machines/<tag>.md` | Each machine's daily usage record and coverage checkpoint, written by its own usage publisher into the notes repo. The journal reads every machine's; no machine writes another's. |
| `.agent/raw/`, `.agent/live.json`, `.agent/sessions/` | Hooks and CLI only; ignored by Git. |
| `.agent/scratch/` | Manager drafts; promote durable decisions into features. |
| `notes/` | Owner's notes; manager never writes here. |
| `harness/owner/`, `harness/voice.md` | Private owner rules, practices, calibration, and voice samples. |
| `harness/`, `.agents/skills/`, `src/agent_cli/`, `bin/agent`, `tests/` | Manager-owned sources and procedures; see [[harness/maintenance]]. |
| `.obsidian/`, `harness/obsidian/` | Curated config and view sources; see [[harness/obsidian]]. |
| `agent.yaml`, `../repos/` | Owner registry; repos sync manages sibling clones and worktrees. |
| `../Agent-worktrees/<name>/` | Harness manager worktrees from `worktree_new`; setup grants this parent on both clients. |
| `.agent/notes-root`, `.codex/config.toml`, `.claude/settings.local.json` | Setup and notes-link state; per machine, gitignored; CLI only. |
| `.agent/install.json` | This install's random token, minted by the first `dispatch new` and written into handoffs as `install:` (ADR-0036); CLI only. |
| `vendor/caveman` | Submodule; never edit its checkout. |

`.agent/` is machine-local. It is gitignored and not in the notes repo, so deleting a clone
deletes its session records, leases, peer queues, raw captures and preserved transcripts. Before
wiping a clone whose evidence a retro or handoff still needs, ask the owner to run `bin/agent session export
<folder> --feature <NNN>` with a folder outside the clone (`--feature` is optional). It copies those records with a SHA-256 manifest
and leaves the originals in place. `--feature` limits only the raw captures; session records,
tab logs, peer queues and leases span features and always come along. The export is private:
captures hold your prompts and hook payloads, and peer queues hold manager messages, so keep
it out of any public repo. To clear stale session records instead, ask the owner to run `bin/agent session
prune --dead` or `bin/agent session rm <id>`, never a hand delete.

`src/agent_cli/notes.py:PRIVATE_SET` is the canonical private-path inventory. The plugin
inventory and versions are in [[harness/obsidian]] and `PLUGIN_SOURCES`. Runtime dependencies
are in pyproject.toml; the CLI implementation is in `src/agent_cli/`.
