# Owner rules

Standing rules that hold only for this owner. Hand-edited by the owner, or by an agent at
the owner's request. Each entry has a date and a one-line why. The generic rules that ship
with the harness are AGENTS.md's standing rules, which load every session; this file is private and loads from the skills that need it.

## YYYY-MM-DD — the rule in one line
What the rule is.
Why: the incident or the reason, in one sentence.
Mechanism: what holds it (a hook, the CLI, a skill step, or "rule only").
