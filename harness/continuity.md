# Manager continuity

Use these templates for manager handoffs and restart notes. Keep the note in its feature.
Read available records before declaring a dependency. Record authorization and attempt caps
without inferring a reset. End each note with a concrete first action the next turn can execute.

## Handoff template

```text
Feature: <number, slug and title>
State: <finished work and evidence paths>
Authority: <owner's grant and remaining limits>
Dependencies: <what is waiting, who owns it, and which records can be read now>
Remaining work: <open task numbers and acceptance>
First action: <one concrete tool call or record read with resolved operands>
```

## Restart template

```text
Feature: <number, slug and title>
Pinned head: <commit and branch>
Read: <plan, log and evidence paths>
Authority: <owner's grant, attempt usage and remaining limits>
Continue: <available work and any external dependency>
First action: <one concrete tool call or record read with resolved operands>
```
